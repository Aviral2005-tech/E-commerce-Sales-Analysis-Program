# E-commerce-Sales-Analysis-Program

## Project Overview

This project analyzes e-commerce sales data using Python, Pandas, and Matplotlib. It demonstrates the complete data analysis pipeline, including data loading, cleaning, analysis, visualization, and reporting.

## Features

- Load CSV dataset
- Clean missing values
- Remove duplicates
- Calculate sales metrics
- Create two charts
- Generate analysis report

## Technologies Used

- Python
- Pandas
- Matplotlib

## Installation

```bash
python -m pip install pandas matplotlib```

## Run

```bash
python "E-commerce sales_analysis.py"```
